# Rotina da equipe no GitHub

1. Entrar com a própria conta e aceitar o convite de colaborador do repositório.
2. Abrir o README da seção, consultar os documentos pelos links e escolher a tarefa.
3. Desenvolver a redação no arquivo texto.md da seção, ou alterar o código e os dados compartilhados quando essa for a tarefa.
4. Criar uma branch por tarefa e abrir uma proposta de alteração (pull request).
5. Solicitar a revisão do grupo e incorporar na main após resolver os comentários.
6. Registrar a versão dos cálculos utilizada no texto e nas figuras.

Os documentos do Drive ficam acessíveis pelos índices do repositório. A permissão do Drive é separada da permissão de edição no GitHub. Consulte [Acesso e colaboração](ACESSO_E_COLABORACAO.md).

Dados e modelos são comuns às quatro seções. Evite criar cópias independentes do pipeline por integrante; as alterações devem manter uma base comum e revisada.
