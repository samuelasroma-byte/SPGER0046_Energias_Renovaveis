# Rotina da equipe

1. Escolher uma tarefa da sua seção e consultar seu README.
2. Fazer as leituras e redigir no documento oficial do grupo.
3. Para código ou documentação versionada, criar uma branch curta por tarefa.
4. Abrir uma proposta de alteração para revisão por outro integrante.
5. Incorporar na versão principal após resolver os comentários.
6. Registrar a versão dos cálculos utilizada no texto e nas figuras.

Não é necessário criar uma instalação diferente ou copiar o pipeline inteiro para cada integrante. A divisão é editorial; dados e modelos são comuns.
