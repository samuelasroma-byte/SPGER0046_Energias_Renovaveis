## Abrir os documentos do Drive

Ao clicar em um link do Drive, o documento abre no Google Drive e continua armazenado na pasta do projeto de Samuel. A conferência individual de 19/10/2026 encontrou permissão por link nos 605 arquivos. A leitura dispensa login; o integrante também pode entrar com a própria conta Google.

O teste no navegador abriu o PDF A001, com 919 páginas, sem login. Os quatro CSVs originais e os metadados têm também downloads públicos OEDI/PVDAQ, conferidos com resposta HTTP 200 e tamanhos correspondentes ao manifesto.

A permissão por link atual também permite edição dos arquivos do Drive. Essa configuração já existia e foi preservada. A redação, revisão e alterações da equipe acontecem no GitHub; o Drive conserva o acervo consultado pelos links.

## Contas da equipe

A conta Google permite interagir com documentos do Drive. A conta GitHub identifica o integrante nas alterações e revisões do repositório. Uma conta não substitui a outra.

Para consultar os arquivos públicos e abrir os links do acervo, basta acessar os índices. Para editar diretamente no GitHub, cada integrante deve receber e aceitar o convite de colaborador. Os nomes de usuário GitHub dos seis integrantes ainda precisam ser informados para concluir os convites.

## Escrever e revisar no GitHub

1. Entrar na própria conta GitHub e aceitar o convite para colaborar no repositório.
2. Abrir a pasta da seção e seu arquivo texto.md.
3. Criar uma branch para a alteração, editar o texto ou os arquivos e registrar a mudança.
4. Abrir uma proposta de alteração (pull request) para revisão pelo grupo.
5. Incorporar a alteração à main depois da revisão. Usar a mesma rotina para código, dados e figuras.

O repositório público permite consultar e baixar os arquivos publicados. Para editar diretamente como integrante é necessário o convite de colaborador. Esse convite é separado da permissão Google Drive e depende da identificação da conta GitHub de cada pessoa.

Os notebooks são arquivos do repositório. Para executar as células, usar Jupyter ou Colab com as dependências e os caminhos descritos na arquitetura técnica. O visualizador do GitHub serve à leitura do notebook.
