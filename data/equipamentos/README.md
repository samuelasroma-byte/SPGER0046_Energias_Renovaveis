# Equipamentos e inventários técnicos

Estes CSVs foram copiados dos apêndices digitais do dossiê existente, preservando os bytes. São inventários e parâmetros documentados, não novas medições.

| Arquivo | Conteúdo |
| --- | --- |
| [grupos_de_modulos.csv](grupos_de_modulos.csv) | Grupos, quantidades e descrição dos módulos do cadastro. |
| [inversores.csv](inversores.csv) | Inventário das 24 unidades, modelo e campos conhecidos/ausentes. |
| [montagem.csv](montagem.csv) | Suporte, geometria e montagem cadastrados. |
| [instrumentos.csv](instrumentos.csv) | Instrumentação e identificação da estação. |
| [medidores.csv](medidores.csv) | Referência de geração CA observada. |
| [dicionario_completo_125_canais.csv](dicionario_completo_125_canais.csv) | Colunas, unidades, agregações, disponibilidades e estatísticas dos canais. |
| [metadados_todos_os_campos.csv](metadados_todos_os_campos.csv) | Campos do cadastro original em forma tabular. |
| [metadados_originais_integrais.json](metadados_originais_integrais.json) | Cadastro integral preservado no dossiê. |
| [inventario_arquivos.csv](inventario_arquivos.csv) | Cobertura e cadência dos arquivos observacionais. |
| [configuracao_completa_modelo.csv](configuracao_completa_modelo.csv) | Configuração registrada no dossiê; a fonte executável atual é config/projeto.json. |

Os parâmetros CEC usados no cálculo ficam em [modulo_cec.json](../../config/modulo_cec.json) e [inversor_cec.json](../../config/inversor_cec.json). A presença do registro CEC não comprova a variante física instalada. A rastreabilidade das cópias está em [proveniencia_arquivos.json](proveniencia_arquivos.json).
